# Eddiebot Creator Portfolio

A vivid, responsive personal portfolio website for **Eddiebot Creator**. It is built with HTML, CSS, and JavaScript so it can be hosted easily on GitHub Pages and shared as a public link.

## Project Description

This portfolio presents Eddiebot Creator as a creative developer with a bright, energetic visual style. It includes a hero section, sticky navigation, project showcase cards, project search and filters, responsive layouts, dark mode, scroll reveal animations, skills, and contact links.

The goal of the project is to provide a professional online home for future web development work, GitHub projects, UI experiments, freelance opportunities, and personal branding.

## Features

- Responsive layout for desktop, tablet, and mobile.
- Vivid visual style inspired by blue, pink, and yellow portfolio design systems.
- Project gallery with search and category filters.
- Light and dark theme toggle with saved preference.
- Scroll reveal animations.
- Contact links for email, GitHub, and LinkedIn.

## Customize

Edit these files:

- `index.html` for your bio, project titles, email, GitHub, and LinkedIn links.
- `style.css` for colors, spacing, and visual style.
- `script.js` for filters, search, animation, and theme behavior.

Search for the project cards in `index.html` to replace the sample projects with your own work.

## Publish With GitHub Pages

1. Create a new GitHub repository.
2. Push these files to the repository.
3. In GitHub, open `Settings > Pages`.
4. Set the source to your main branch and root folder.
5. GitHub will give you a shareable portfolio link.

## Local Preview

Open `index.html` in a browser, or use any simple static server.
